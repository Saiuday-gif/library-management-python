# 📚 Library Management System (Python OOP)

This project is developed as part of the **VENHAN Backend Assignment**.  
It is a **console-based Library Management System** implemented in **Python**, designed using **Object-Oriented Programming (OOP)** principles.  
The system allows managing books and borrowers, handling borrowing and returning operations, and searching for book availability — all in-memory, without using databases.

---

## 🚀 Objective

The goal of this project is to demonstrate Python **OOP design and implementation** through a real-world example of a library system.  
It helps to understand **encapsulation, inheritance, and modularity** using class-based architecture.

---

## 🧠 Features

- Add, update, and list books.
- Register borrowers and update their details.
- Borrow and return books with due date tracking.
- Prevent borrowing when books are unavailable.
- Search for books by title, author, or genre.
- Overdue detection using `datetime`.
